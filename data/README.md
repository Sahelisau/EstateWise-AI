# Dataset sources and handling

The files in `data/raw/` are original archives received for this project. They remain unchanged. The archive copies, cleaned listing rows, record-level evaluation exports, and trained binary models are excluded from Git until the source terms and redistribution conditions are fully confirmed. The `.gitignore` rules are deliberate; do not remove them until completing that review.

## Primary India dataset

- **Name:** House Price (India), by Juhi Bhojani
- **Source:** [Kaggle dataset page](https://www.kaggle.com/datasets/juhibhojani/house-price)
- **Download date:** The archive was received in this project on 2026-11-03; the original Kaggle download date was not recorded.
- **Archive:** `data/raw/india_property_listings_81_cities.zip`; contains `house_prices.csv`.
- **Raw size:** 187,531 rows and 21 columns.
- **Geography and property scope:** 81 location labels in India; flat listings only. There are no listing dates or structured locality values.
- **Target used:** `Amount(in rupees)`, parsed from lakh/crore strings. Some source rows do not contain a usable amount.
- **Useful source fields:** `Title` (bedrooms extracted from BHK text), `location` (city label), `Carpet Area`, `Super Area`, `Bathroom`, `Balcony`, `Furnishing`, `facing`, `overlooking`, `Ownership`, and `Transaction`.
- **Other source fields:** `Index`, `Description`, `Price (in rupees)`, `Status`, `Floor`, `Society`, `Car Parking`, `Dimensions`, and `Plot Area`. Several are free text, duplicated price information, or not used by this model.
- **Attribution:** Juhi Bhojani; preserve the creator credit and link to the Kaggle page if redistributing the source or modified data.
- **Reported license:** A [third-party mirror lists CDLA-Sharing-1.0](https://huggingface.co/iaac-maai/day2-example-house-price), but the Kaggle license metadata could not be directly verified during repository preparation. Treat the exact dataset license as **unconfirmed** until checked on Kaggle.
- **Redistribution status:** Do not publish the raw archive or modified listing rows until the license shown on the Kaggle source page has been verified and all its conditions are met. The official [CDLA-Sharing-1.0 agreement](https://cdla.dev/sharing-1-0/) requires published source or enhanced data to remain under that agreement, retain provider attribution, mark modifications, and include or link the agreement.
- **Current processed output:** Locally, `data/processed/cleaned_properties.csv` has 63,108 rows across 81 location labels. Cleaning removes duplicate rows, non-sale/unknown transactions, unusable prices or areas, and values outside documented sanity bounds. The processed output is generated by `python -m src.eda` and is ignored by Git.
- **Leakage note:** `source_index` is retained for traceability but is not a model feature. `price_per_sqft` is calculated using the target price and is used only for analysis, not training.

### Obtain the primary archive

Download the dataset from Kaggle, then place the original ZIP at `data/raw/india_property_listings_81_cities.zip`. The project does not include Kaggle credentials or an automatic download script. After downloading, run `python -m src.eda` to regenerate the cleaned data and EDA outputs.

## Secondary archive

- **Archive:** `data/raw/house_price_india_secondary.zip`; contains `House Price India.csv`.
- **Inspected size:** 14,620 rows and 23 columns; no missing values in the inspected file.
- **Limitations:** No city or locality field; coordinate values fall outside India; currency meaning is unclear. It is excluded from the India model.
- **Source, download date, license, and attribution:** Not provided with the archive. Do not redistribute or use it in a public release until provenance and rights are established.

## Reproducibility and public release

For a public repository, include the raw archive only if its source license is verified and redistribution is permitted. If the license cannot be verified, leave the archive local and tell users to download it themselves. Cleaned rows and record-level prediction/error exports can expose source observations; do not publish them until the source terms have been reviewed. Aggregate charts and metrics are generated outputs and should remain clearly attributed to the source dataset.
