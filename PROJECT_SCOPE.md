# Data and Model Scope

EstateWise AI estimates historical residential flat asking prices from property details. This is a supervised regression task.

The dataset is a cross sectional snapshot. It does not include listing dates or repeated price observations over time, so the model does not forecast future prices. The app also does not show live property availability.

Prices in the source are asking prices, not confirmed sale prices. Treat estimates as project outputs for exploration, not current market quotes or professional valuations.
